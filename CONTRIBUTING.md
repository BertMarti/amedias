# Cómo contribuir

¡Gracias! «a medias» quiere seguir siendo pequeña, rápida y segura.

1. Abre un issue antes de un cambio grande.
2. `npm ci` y `npm run check` en verde (con Node < 24: `./dk.sh npm run check`).
3. Sigue las [reglas de AGENTS.md](AGENTS.md#reglas-bloqueantes-en-revisión); son bloqueantes.
4. Commits con [Conventional Commits](https://www.conventionalcommits.org/es/).
5. En el PR: qué cambia, cómo lo probaste (también en el móvil) y su impacto en seguridad.

¿Una vulnerabilidad? Lee [SECURITY.md](SECURITY.md).
